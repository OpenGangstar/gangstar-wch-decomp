# MSADPCM stream constructor

The stream constructor initializes both channel states and the input
buffer, reads the WAV fact and data chunks, and derives the PCM size
from the sample count in the fact chunk.

```text
OK  _ZN20CSoundDecoderMSADPCMC1EP7__sFILEP10RiffHeaderP12FormatHeader  0x003513d9  224 bytes
OK  _ZN20CSoundDecoderMSADPCMC2EP7__sFILEP10RiffHeaderP12FormatHeader  0x003513d9  224 bytes
```
